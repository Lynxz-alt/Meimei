## 🚀 Cara Deploy ke Streamlit Cloud

### 1. Push ke GitHub

```bash
# Clone / buat repo baru di GitHub, lalu:
git init
git add .
git commit -m "🎂 Happy Birthday Meimie!"
git branch -M main
git remote add origin https://github.com/USERNAME/meimie-birthday.git
git push -u origin main
```

### 2. Deploy di Streamlit Community Cloud (GRATIS!)

1. Buka **[share.streamlit.io](https://share.streamlit.io)**
2. Login dengan akun GitHub kamu
3. Klik **"New app"**
4. Pilih repo **`meimie-birthday`**
5. Branch: `main`
6. Main file path: `app.py`
7. Klik **"Deploy!"**

Dalam 1-2 menit, website Meimie sudah live dengan URL seperti:
`https://meimie-birthday.streamlit.app` 🎉

## 💻 Jalankan Lokal

```bash
# Install dependencies
pip install -r requirements.txt

# Jalankan
streamlit run app.py
```

Buka browser di `http://localhost:8501` 🌸
